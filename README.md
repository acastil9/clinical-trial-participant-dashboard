# Clinical Trial Participant Dashboard

An interactive clinical research analytics prototype designed to explore patient recruitment, pre-screening outcomes, eligibility determination, and study enrollment.

## Project Overview

This project demonstrates how clinical research teams could visualize participant progression and identify opportunities to improve screening and enrollment rates.

## Features

- Interactive participant tracking dashboard
- Pre-screening and eligibility status monitoring
- Recruitment conversion analysis
- Laboratory processing time analysis
- Study and site filtering
- Participant drop-off visualization
- Demonstration data export

## Technologies

- HTML
- CSS
- JavaScript
- Synthetic demonstration data

## Purpose

Explore how accessible data visualization and workflow tracking can support evidence-based decisions in clinical research operations.

## Disclaimer

This is an independent educational prototype. All participant records are fictional. The application is not affiliated with, endorsed by, or intended for clinical use by any research organization.

It does not connect to electronic medical records, clinical trial management systems, or real patient databases.
